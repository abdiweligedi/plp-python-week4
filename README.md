# Your First Functions - Week 4

`welcome.py` defines a welcome function and uses it to greet three learners.

`toolbox.py` contains three functions for doubling numbers, checking passing scores, and creating greetings.

The hardest function to write was `greet` because it uses a default parameter for the greeting. I had to make sure it uses "Hello" when no greeting is provided but uses the supplied greeting when one is given.
