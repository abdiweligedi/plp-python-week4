# Grades, Eligibility & Smart Decisions

- `grade_classifier.py` — Checks a student's score and assigns a grade from A to F.
- `eligibility_checker.py` — Checks whether a person is eligible to join a local coding club.
- `atm_menu.py` — Simulates an ATM withdrawal and checks the account balance.
- `screenshots/` — Contains screenshots of the programs running.

## When is elif better than several separate if statements?

`elif` is better when you have several conditions but only one result should happen. For example, when classifying grades, only one grade should be given for a score. Using `elif` makes the program easier to read and prevents unnecessary conditions from being checked after a match is found.
